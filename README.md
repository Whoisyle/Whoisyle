Profile

I build and experiment with security tooling and software, with a focus on offensive security, red-team tradecraft, cloud security, network reconnaissance, and web application security. My work combines hands-on technical learning with practical engineering: writing tools, testing workflows in authorised environments, and documenting what I build.

• Offensive security: reconnaissance, attack-surface mapping, service enumeration, and security assessment workflows.
• Cloud & infrastructure: Linux environments, container fundamentals, cloud security concepts, and infrastructure hardening.
• Application security: web technologies, API testing concepts, secure development, and vulnerability research in authorised environments.
• Engineering: Python automation, scripting, Git-based workflows, and full-stack product development.
• Current build areas: Amari security tools and Vossie Marketplace.

> I aim to make security work repeatable, measurable, and responsible. All testing should be performed on systems I own or have explicit permission to assess.

Engineering Principles

• Evidence over assumptions: validate findings and document reproducible steps.
• Secure by design: consider access control, secrets, logging, and least privilege from the start.
• Automation with purpose: make repetitive tasks consistent, reviewable, and easier to maintain.
• Clear documentation: include scope, setup, usage, limitations, and responsible-use notes.
• Continuous improvement: learn from labs, code reviews, testing, and project iteration.
